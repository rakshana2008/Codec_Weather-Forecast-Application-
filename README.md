# Codec_Weather-Forecast-Application

## About the Project
A weather forecast application that provides real-time weather information for different cities using the OpenWeatherMap API.

## Technologies Used
- Frontend: React.js
- Backend: Node.js
- Framework: Express.js
- API: OpenWeatherMap

## Features
- Search weather by city name
- Display current temperature
- Show humidity and wind speed
- Display weather conditions
- Handle API errors
- Dynamic weather updates

## Project Requirements
- External API integration
- Secure API key management
- Error handling
- Responsive user interface
- Environment-based configuration

## Installation
1. Clone the repository.
2. Install dependencies using npm install.
3. Configure your OpenWeatherMap API key in the .env file.
4. Start the server using npm start.

## Objective
To develop a user-friendly weather application
